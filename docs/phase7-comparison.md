## Fixes made after pass 3 (2026-11-22); compiled and unit-tested, not yet seen in game
- **P0 table rewards**: `Ids.tableId(params)` turns FTB's decimal `table_id` into the hex key of the table file; used by the granter, the reward icon, the table screen and the editor. New table rewards are written like FTB writes them (numeric id plus `exclude_from_claim_all: true`). Test: `IdsTableTest` (the reference value 8688099075117598374 maps to 78925413C9C8C6A6).
- **Item count**: `Task.itemCount` reads the count nested in `item: {id, count}` or beside it; used by the task, the reward line, the granter and the icon badge.
- **Icons**: table rewards show the first table entry's icon; advancement reward = grass block for `/root` (else wheat); toast = sign; fluid task = filled bucket with `1 B`; kill task shows its count under the egg.
- **Chapter image**: a vanilla painting name such as `minecraft:backyard` is looked up in this game's painting sheet and drawn (its outline in edit mode is not drawn yet).
- Still open from the list: description hover text (P1/P2), fluid and stat tasks do nothing when played (P1), panel texture and checks, map background, info button, dependency line style (P2).

### Description hover text (2026-11-22; compiled and unit-tested, not seen in game)

A span carries its hover text; `DescriptionView` reports it and the quest window shows it as the tooltip of that span (it replaces the link's own tip when both exist). Test `hoverAndClickEventsInTheNewSpellingAreRead` uses the exact entry FTB saved in the reference book. `translate` keys are shown as written, as FTB does when the key has no translation. The editor side (Quest and Hover toolbar buttons, colour picker) is still missing.

### Fluid and stat tasks (2026-11-22; compiled, not seen in game)
- **Stat**: `TaskTracker.statOf` maps FTB's `minecraft:mob_kills` style names to the 1.12.2 statistics of the basic list (kills, deaths, jumps, damage, play time, distances, bred, fished, trades...) and the task progresses from the player's statistics up to `value`. A name outside that list is reported by `/rquests problems` as inert instead of silently doing nothing.
- **Fluid**: the task counts the millibuckets of the named fluid carried in the player's inventory containers (buckets, tanks) up to `fluid.amount` (default 1000); it does not consume them (FTB's consume-by-clicking is not implemented). `water` for `minecraft:water`; unknown fluids are listed as inert.
- Manual check to do: hold a water bucket (the Fluid task should complete) and kill any mob (the Stat task counts kills; its `value` is 1 in the reference book).
